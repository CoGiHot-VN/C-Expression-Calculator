# C++-Expression-Calculator
My very first program in life. I'm new to C++ and this is my mid-term test
It's just a simple calculator using long long so it just can work in small numbers

Introduction:
This program calculates arithmetic expressions and is written in C++.

Functions:
Performs addition (+), subtraction (-), multiplication (*), and division (/).
Ensures that multiplication and division are prioritized over addition and subtraction, without parentheses
Supports multiple consecutive expressions.
Checks for syntax errors('=' is required at the end of expression)
Detects division errors.

Language: C++
Library: iostream

Example:
Input: 2+3*4=
Output: Ket qua: 14
